# Contributing

Read [development conventions](docs/development/contributing.md), [testing](docs/development/testing.md), and [architecture](docs/architecture.md). This package follows the sibling Table Builder quality standards: strict PHP, final concrete classes, PHPStan max, 100% type and line coverage, strict TypeScript, browser/accessibility checks, and distribution/documentation verification.

Changes to the wire contract must update PHP, SDK types, generated schemas, React behavior, the shared fixture, and consumer guidance together. See [release checks](docs/development/releasing.md).
